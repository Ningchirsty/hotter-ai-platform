# 视频创作前端发布

仅发布视频前端：16 个云端视频型号（排除 HappyHorse）、中文模式、创作能力与时长／分辨率选择、官方公开单价、Media 倍率和参数组合预计费用。报价快照保留核对时间，Seedance 按公开样例估算 Token，参考视频额外用量另计。

本地视频任务仍使用既有创建、执行、轮询、素材和播放接口。图像创作、AI 灵感、后端、数据库、生产配置均未修改。本次不发布云端视频后端，所以云端提交与素材上传保持禁用，不请求尚未部署的接口、不产生付费生成。

发布采用现有 Frontend CI 和不可变 GHCR 镜像，再调用现有 `deploy-frontend-poc.yml`；不调用后端部署工作流。生产通过 `version.json` 和页面交互验证。
