## 三、步骤 1：建 7 张新表

```bash
# 把 5 份脚本送进 mysql 容器并按顺序执行（顺序彼此无依赖，但按依赖强弱排更稳）
for f in aig_studio_change_proposal aig_agent_resource_binding aig_studio_artifact_draft \
         aig_studio_copilot_turn aig_sandbox_artifact_download; do
  sudo docker cp script/sql/$f.sql <mysql容器>:/tmp/
  echo "=== $f"
  sudo docker exec -i <mysql容器> sh -c \
    'mysql -uroot -p"$MYSQL_ROOT_PASSWORD" --default-character-set=utf8mb4 <库名> < /tmp/'$f'.sql' \
    || echo "FAILED: $f"
done
```

**期望输出**：每份脚本最后一行各打印自己的 marker（见 §一 表格）。
**没有 marker 就是没跑完**——`docker exec` 返回 0 但缺 marker 的情况要当成失败处理，
不要只看 `exit code`（runbook §3.3 记录过"重放 exit=0 但数据已被清掉"的先例）。

## 七、步骤 5：发布后验收（**两项必做**）

### 5.1 服务令牌开启后的回归（**风险最高的一项，先做**）

本轮唯一改到"所有请求都经过"的行为面就是 `aigov.service-token.enabled: true`。要验的是
**不带令牌的请求完全不受影响**：

```bash
# ① 不带 X-Service-Token：治理台页面/接口照常（期望 401=未登录而非 403/500）
curl -s -o /dev/null -w '%{http_code}\n' http://<生产域名>/aigov/agent/page

# ② 带一个错误令牌：应被拒绝（期望非 2xx，且报文里能看出是令牌不认）
curl -s -o - -w '\n%{http_code}\n' -H 'X-Service-Token: not-a-real-token' \
     http://<生产域名>/aigov/agent/page

# ③ 带正确令牌：应在**不带登录态**的情况下通过（用 §07 §12.2 签发的令牌）
curl -s -o - -w '\n%{http_code}\n' -H 'X-Service-Token: <签发的令牌>' \
     http://<生产域名>/aigov/agent/page
```

**判定**：① 必须与开启前一致；② 必须被拒；③ 若还没有签发令牌（F-08 未定的现状），
第 ③ 步可暂缓，但 ①② 必须做。**任何 ① 出现 403/500，立即回滚该项配置**（见 §八）。

### 5.2 沙箱产物端到端（ADR-016 §实施顺序第 4、5 步）

按下面顺序**在生产真跑一遍**，全部通过才算这批代码可用：

1. 宿主：确认镜像在白名单里（`/etc/hotter-sandbox/images.allow`；**不存在=拒绝运行**，这是刻意的 fail-closed）→
   放一个作业（`request.json` 必须**原子写入**：先写 `.tmp` 再 `mv`）→ 跑一轮 `sandbox-worker.sh --once`；
2. 平台：把宿主 `result.json` **原样**登记进沙箱账本（不要手改、不要只挑几个字段填）；
3. 平台：打开发布推进对话框，对同一版本登记**产物**（逐文件上传，字节数与 sha256 必须与清单一致）；
4. 平台：产物列表应显示"声明 N 个、已上传 M 个"，**漏传的必须点名**；
5. 平台：**下载**其中一个产物 → 本地 `sha256sum` 应与清单一致；响应头应为
   `Content-Type: application/octet-stream` + `Content-Disposition: attachment` + `X-Content-Type-Options: nosniff`；
6. 平台：展开「下载记录」，应看到刚才那一条（谁、什么时间、从哪个 IP、下发的 sha256/bytes）；
7. 平台：用错误字节数／错误 path／篡改过的文件再试一次 → 必须**被拒**，且**对象存储里不新增对象**；
8. 清理：临时版本、发布事件、账本行、作业目录与容器回到原状。

**step 5/6 是最关键的**：它同时验证"只信账本"的三道校验与"先记留痕再下发"。
如果下载时 sha256 对不上，**先停下载入口**，不要当成普通 bug 处理（那是"账本与字节不一致"的安全信号）。
