## 二、★验证内容哈希修复真的生效（**本单最关键的 3 步**）

**为什么必须走接口**：页面「新建草稿」走的是服务端骨架，而骨架**本来就是对象路径**，
新旧代码表现一致 ⇒ **在界面上看不出差别**。只有"调用方自己传 contentJson 且省略字段"这条入口能区分。

### 步骤

| # | 动作 | 判据 |
|---|---|---|
| 1 | 新建草稿，`contentJson` **故意只给两个字段、省略 `promptSections`**：<br>`{"agentName":"A","objective":"出脚本"}` | 返回 `code=200` 且拿到 `draftId` |
| 2 | 读这条草稿的详情，看 `data.contentJson` | **必须出现 `"promptSections":{}`** ⇒ 新代码在跑<br>（旧代码这一串里**不会**有这个键——这就是新旧的分水岭） |
| 3 | 用草稿里**真实的** `objective` 值再提一条提案（`/objective` 改成同一个值） | **必须被拒**，消息含 `提案没有产生任何内容变化`<br>（旧代码会返回 `code=200` 并落库 ⇒ 失败） |

## 五、工具/知识绑定回归（G6；已在 2026-10-12 实测通过，部署后复跑一遍）

前置：需要一个**声明过 `allowed_tools` 的 Agent 版本**。
现有 4 个内置版本**声明全为空**，所以只能验负向；要验正向，得先有一条带声明的版本
（`13-…md` §11 造的 `mt2026a` 那个版本即属此类，若已清理则需重建）。

| 用例 | 判据 |
|---|---|
| 绑定未声明的编码 | 拒绝，消息含 `该版本没有声明任何工具（allowed_tools 为空）` |
| 绑定 `forbidden_tools` 里的编码（如 `shell`） | 拒绝，消息含 `该版本明确禁止了工具「shell」` |
| 绑定已声明的编码 | `code=200`；随后 `declared-resources` 里该项 `bound=true` |
| 同范围重复绑定 | 拒绝（**等 9 秒再发**，否则会被 `@RepeatSubmit` 抢先拦成"不允许重复提交"） |

## 六、服务令牌回归（C3；**这一步会产生一条令牌记录**）

| 用例 | 判据 |
|---|---|
| 不带 `X-Service-Token` 访问 `/aigov/agent/list` | `401 登录状态异常`（与开启前一致） |
| 带无效令牌 | `401 服务令牌无效、已停用或已过期`，**不回落**到会话认证 |
| 签发令牌 → 用令牌 + `clientid` 请求 | `200`；**明文只在签发响应出现一次**，列表里没有明文/哈希 |
| 缺 `clientid` | `401 缺少 clientid 请求头…` |
| scope 未覆盖的接口 | `403`（最小权限生效） |
| 吊销后再请求 | `401`（立即失效） |

⚠️ 令牌表**没有删除接口**，只能吊销（行会留下）。做完请吊销并记下 `token_id` 备查。

## 七、失败时怎么办

| 现象 | 判断 | 处置 |
|---|---|---|
| §一 出现 404 | 新镜像**没上去** | 回滚确认部署入口的镜像 tag/摘要，重发 |
| §二 第 2 步**没有** `promptSections` | 跑的是**旧后端** | 同上；此时 §二 第 3 步必然被接受（旧行为） |
| §二 第 3 步**被接受**（200） | 修复**没生效**（或代码回退了） | 检查镜像里 `AigStudioDraftServiceImpl#canonicalize` 是否走了对象往返（`13-…md` §11.3） |
| §三 ① 0 行 / granted_roles=0 | SQL 种子没跑或 `menu_id` 又被占 | 重跑 `script/sql/aig_agent_registry_menu.sql`；若 `0027` 也被占则换 `0028`（改脚本两处） |
| 只有 §六 失败 | 令牌通道问题，与本次改动无关 | 先按 `07-部署与发布运行手册.md` §十二 回滚开关（`enabled:false`），再排查 |

**回滚后端镜像**：镜像回退到上一个 tag 即可；**新表与菜单行不必回滚**（旧代码不读它们，
而且第 11 章的 7 张表/权限本身不是本次修复的一部分）。

## 九、说明：这次部署**不会**改变什么（别误判）

- **Copilot 的开关状态**：`aigov.studio.copilot.enabled` 在 `application-prod.yml` 里**已于 2026-10-12
