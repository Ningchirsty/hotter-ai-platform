# 图像／视频创作工作台改造

## 基线与范围

基于 origin/main（52f933d9c）实现，仅修改前端；后端接口、工作流契约、菜单、任务与素材存储均沿用已有实现。云端为待接入入口，不能提交。

## 页面与交互

- 视频创作与图像创作使用一致的左右框架，顶部与底部对齐；小屏上下排列。
- 左侧保留本地生成的所有能力、上传预览、参数与真实提交。云端切换不销毁本地草稿。
- 右侧为独立的图像／视频参考库。图像分类保留原设计分类；视频分类为产品广告、材质与光影、人物叙事、空间与建筑、自然风景、镜头运动。支持搜索、模型／能力筛选、页码与上一页／下一页、浏览器内收藏。
- 先选择作品，再查看模型与能力推荐。带入后检查服务端工作流编码、能力编码与发布状态；上传或提交过程中不允许推荐动作重置表单。
- 同一能力下保留自己的已上传素材；切换能力沿用原页面重置行为。案例封面不会作为生成输入自动上传。
- 所有输出、任务详情、取消／重新执行、预览／下载与素材管理保留在原有「我的任务」「素材库」中。视频提交成功后自动进入任务列表。

## 内容与推荐边界

图像库使用用户提供的参考截图，视频库使用 Mixkit 公开实拍参考视频；视频详情含播放器、来源链接与加载失败提示。它们是灵感参考，不是平台任务产出或模型生成效果。页面不自动上传案例或截取视频帧作为任务输入。

每个库首批各 9 个独立案例，每页 6 个，共 2 页。模型与能力筛选来自真实工作流的编码、能力、PUBLISHED 与 submittable 状态，已退役／未发布／未接入的方向不进入推荐。搜索、分类、模型或能力变更回到第一页，收藏和状态缩减时页码自动收敛。推荐为显式能力规则，正式案例内容接口与在线 AI 推荐留待接入。新增模型需注册对应案例方向及创建表单适配；并不因新增工作流便假定所有案例可复现。

## 关键位置

- frontend/src/components/CreativeInspiration：共享瀑布流、收藏、作品详情、能力推荐与本地／云端选择。
- frontend/src/assets/styles/creative-workbench.scss：两个页面共用的全视图配色与创建页布局。
- frontend/src/views/image/index.vue、video/index.vue：接回各自真实接口与表单。
- catalog.spec.ts：推荐方向匹配实际契约、图像／视频隔离、发布状态与云端提交阻止测试。

桌面布局核对：1440px 宽时左右两块顶部和底部坐标一致，无横向溢出；窄屏自动纵向排列。

## 统一配色

视频和图像的创建、任务、素材库，以及灵感推荐、详情、产出预览、确认弹窗和下拉菜单统一使用浅底、白色卡片与淡紫色主题。任务状态标签保留绿／黄／红语义，提升浅底文字对比。主题仅作用于创作页面及带明确类名的相关弹层，不覆盖平台其他模块；布局、接口、上传与生成逻辑不变。

## 云端模型选择界面（2026-10-07）

视频候选：MiniMax Hailuo 2.3、Google Veo 3.1；图像候选：Qwen-Image Plus、Qwen-Image Edit Plus。均为 PENDING 展示目录，不代表平台已经注册或可调用。模型能力与输出组合参考组件目录 cloud-models.ts 中链接的官方文档，正式接入时以供应商、区域、模型版本和平台审核后的能力契约为准。

CloudGenerationForm 在两个创建页面独立挂载；本地与云端用 v-show 切换，保留当前创建页面内的草稿。模型与能力切换保留各自独立参数和素材；离开创建视图或路由后不承诺保留。素材仅使用本地 File / blob URL，未调用上传或生成接口，卸载时回收 URL。10 MB 是这版素材选择控件的产品限制，正式接入还需逐模型校验格式、大小、分辨率和服务限制。

云端提交沿用 canSubmitLocal 的来源隔离检查，始终禁用；不可将云端草稿发送到本地 createTask。前端不包含密钥或服务地址。续写入口仅说明未来从同模型已完成任务选择，不允许任意视频冒充可续写资产。费用未配置时不显示虚构价格。灵感推荐仍依据已发布的本地能力，应用方向会切回本地。

正式接入需扩展现有模型治理的生成媒体能力契约，提供不含密钥的目录投影，绑定 provider / model / capability / constraints / readiness；并由平台后端处理鉴权、素材转存、异步任务状态和费用。现有 CHAT / VISION 分类不能直接当作视频或图像生成模型。
