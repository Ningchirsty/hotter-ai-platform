# 03 数据字典与字段规范

> 权威来源：`sql/V1__talent_schema.sql`（表结构，列注释即字段规范）与 `sql/V2__talent_menu_role_dict.sql`（字典数据）。
> 本文件只做**跨层映射**：数据库列 ↔ Java 字段 ↔ 字典类型 ↔ 枚举类。改字段时三处必须同步。

**审计字段规范**：除 `tl_sensitive_audit` 外，所有表都有
`del_flag char(1) default '0'`（`@TableLogic`）+

`tl_sensitive_audit` 是追加型审计表，只有 `operate_time`，不做逻辑删除。

## 3. 人才主档字段规范（易错点）

| 列 | Java 字段 | 规范 |
|---|---|---|
| `phone_cipher` | `phoneCipher` | `@EncryptField`。**前提**：`mybatis-encryptor.enable=true`，否则等同明文（`TalentSecurityGuard` 启动会告警）。**禁止**作为查询条件 |
| `phone_hash` | `phoneHash` | SHA-256(盐 + 标准化号码)，用于重复预检的**等值查询**（框架字段加密无法用于 Wrapper 条件） |
| `phone_tail4` | `phoneTail4` | 后四位，用于"姓名+后四位"弱匹配与检索；**非完整号码** |
| `phone`（VO/BO） | `phone` | 仅内存态（实体上 `@TableField(exist = false)`）。VO 上挂 `@Sensitive(PHONE, perms = talent:profile:phone)` + `phoneMasked` 兜底 |
| `birth_date` / `age_only` / `age_source_date` | `birthDate` / `ageOnly` / `ageSourceDate` | **年龄不落库**，由 `birthDate` 实时计算；只识别到年龄时填 `ageOnly` + `ageSourceDate`，提示待补出生日期 |
| `expect_salary_min/max` | `expectSalaryMin/Max` | 整数**元/月**，展示时由服务端转 `8K-10K` 形式（`expectSalaryText`） |
| `region_code` | `regionCode` | 仅 `GROUP/SZ/ST`；`GROUP` 表示**集团共享**，不是"无归属" |
| `share_scope` | `shareScope` | `REGION` 区域共享 / `GROUP` 全集团 / `GRANT_ONLY` 仅单条授权 |
| `remark` | `remark` | 禁止写入与招聘无关的敏感标签或歧视性评价 |
| `talent_no` | `talentNo` | `TL` + `yyyyMMdd` + 序号，唯一索引兜底，冲突重试 |

## 4. 附件字段规范

| 列 | 规范 |
|---|---|
| `object_key` | `talent-private/{talentId}/{attachmentId}/v{version}/original{ext}`；**绝不出现在任何接口响应中** |
| `oss_id` | 保留列（可空）。一期**不登记** `sys_oss`，避免 `system:oss:download` 形成绕过人才库授权的下载旁路 |
| `version` / `is_current` | 同人才同类型多版本，**仅一个** `is_current='1'` |
| `file_hash` | SHA-256，用于重复文件识别 |
| `scan_status` | 仅 `CLEAN` 可下载；`talent.virus-scan-enabled=false` 时新附件直接置 `CLEAN` 并在 `scan_remark` 留痕 |
| `original_name` | 下载时用 `filename*=UTF-8''` 编码回显，防止中文乱码与响应头注入 |

## 5. 索引与设计依据

| 索引 | 服务场景 |
|---|---|
| `tl_talent(region_code, status, del_flag)` | 区域+状态列表查询（**区域范围强制条件的入口**） |
| `tl_talent(phone_hash)` | 重复预检等值命中 |
| `tl_talent(name, region_code)` | 姓名 + 区域检索 |
| `uk_tl_talent_no(talent_no)` | 人才编号唯一 |
| `tl_talent(contact_date)` | 联系日期区间筛选 |
| `tl_talent_attachment(talent_id, attachment_type, is_current)` | 定位"当前简历" |
| `tl_talent_attachment(file_hash)` / `(scan_status)` | 去重 / 待扫描清单 |
| `tl_sensitive_audit(operate_time, operator_id, action)` | 审计检索 |
| `tl_sensitive_audit(talent_id)` / `(target_type, target_id)` | 按人 / 按对象追溯 |
| `tl_talent_access_grant(talent_id, grantee_type, grantee_id)` | 单条授权判定（每次按 ID 访问都会走） |
| `tl_export_task(create_by, status)` | 本人导出任务列表；`(status, expire_time)` 用于过期清理 |
