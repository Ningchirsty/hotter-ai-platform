> 基线：RuoYi-Vue-Plus v6.0.0。所有接口沿用框架鉴权（Sa-Token）、统一响应 `R<T>`、分页 `PageQuery` → `PageResult<T>`。

## 2. 接口清单

统一前缀 `/talent`。下表「权限」列为 `@SaCheckPermission` 的值。

### 2.1 人才档案 `/talent/profile`

| 方法 | 路径 | 权限 | 说明 | 幂等 |
|---|---|---|---|---|
| GET | `/list` | `talent:profile:list` | 分页检索，服务端注入区域范围 | — |
| GET | `/{talentId}` | `talent:profile:query` | 单条详情（含附件、联系记录、当前用户权限位），服务端脱敏 | — |
| GET | `/fullPhone/{talentId}` | `talent:profile:phone` | 返回完整手机号；写 `VIEW_FULL_PHONE` 审计 | — |
| POST | `/preCheck` | `talent:profile:add` | 重复预检，不落库 | — |
| POST | `` (根) | `talent:profile:add` | 新建（含重复预检）；`duplicateConfirmed=true` 才允许在命中时创建 | `@RepeatSubmit` |
| PUT | `` (根) | `talent:profile:edit` | 编辑（先做单条二次校验 + 可写区域校验） | — |
| PUT | `/archive` | `talent:profile:archive` | 归档 | — |
| GET | `/contact/{talentId}` | `talent:profile:query` | 联系记录列表 | — |
| POST | `/contact` | `talent:profile:query` | 新增联系/面试反馈 | `@RepeatSubmit` |
| GET | `/grant/{talentId}` | `talent:profile:grant` | 该人才授权列表 | — |
| POST | `/grant` | `talent:profile:grant` | 新增/更新授权 | `@RepeatSubmit` |
| DELETE | `/grant/{grantId}` | `talent:profile:grant` | 撤销授权 | — |

**导入简历直接建档**（`/talent/profile/import`，详见 `docs/talent/draft/SPEC-简历导入.md`）：

| 方法 | 路径 | 权限 | 说明 | 幂等 |
|---|---|---|---|---|
| POST | `/import/preview` | `talent:profile:import` | 上传简历（multipart 字段 `file`），本地提取 + 规则抽取，返回候选字段（含来源与置信度）与 `importToken` | `@RepeatSubmit` |
| POST | `/import/confirm` | `talent:profile:add` | 用 `importToken` + 用户确认后的表单值建档，并把简历存为受控附件 | `@RepeatSubmit` |

> 说明：本功能全程在服务端进程内完成（PDFBox / POI / 正则），**不调用任何外部 AI/OCR 服务**，
> 由独立开关 `talent.resume-import-enabled`（默认 `true`）控制，与需审批的 AI 解析
> `talent.parse-enabled`（默认 `false`）互不影响。抽取结果一律作为候选值，必须人工确认才写入主档。

## 4. 数据范围矩阵（服务端强制，**与前端参数无关**）

| 角色 | 可见区域 | 可写区域 | 完整手机号 | 下载附件 | 导出范围 |
|---|---|---|---|---|---|
| 超管 / `talent_admin` | 全部 | 全部 | 是 | 是 | 全部 |
| `talent_hr_group` | 全部 | 全部 | 是 | 是 | 全部 |
| `talent_hr_sz` | `SZ` + `GROUP` | 仅 `SZ` | 是 | 是 | 可见范围 |
| `talent_hr_st` | `ST` + `GROUP` | 仅 `ST` | 是 | 是 | 可见范围 |
| `talent_viewer` | 无（仅单条授权） | 不可修改档案 | 脱敏（需单条 `VIEW_FULL_PHONE` 授权） | 仅单条授权 | 无 |
| `talent_auditor` | 无 | 不可修改业务数据 | 按审批 | 默认否 | 审计范围 |

`GROUP` 是**集团共享档案**，不是"无归属"；`SZ`/`ST` HR 对 `GROUP` 记录**可读但不可写**。

## 5. 强制授权规则（实现层硬约束）

1. 列表查询**必须**由服务端追加 `region_code IN (可见区域)`；`regionCode` 请求参数只能收窄、不能扩宽。
2. 查看详情 / 下载附件 / 导出 / 查看解析 **必须**先加载业务对象并执行区域 + 单条授权二次校验，不能只校验菜单或权限标识。
3. 用人部门对具体候选人的访问走 `tl_talent_access_grant`（带有效期与授权人）。
4. 普通查阅角色返回手机脱敏值；数据库与 HR 接口保存/返回完整号码。
5. 管理员技术身份**不默认绕过**业务敏感数据访问；查看原始简历仍产生审计事件。
6. 附件对象键、存储桶、预签名 URL **不出现在任何接口响应中**。
7. 导出 Excel 中的链接列是应用入口（`https://pm.hottter.cn/talent/profile?talentId=...`），点击后仍需登录与鉴权。
8. 所有以 ID 访问的接口支持幂等键；修改/确认/导出接口加 `@RepeatSubmit`。

## 6. 敏感审计动作字典（`tl_sensitive_audit.action`）

| 动作 | 触发点 |
|---|---|
| `VIEW_DETAIL` | 查看人才详情 |
| `VIEW_FULL_PHONE` | 调用 `/fullPhone/{talentId}` |
| `UPLOAD` | 上传附件 |
| `DOWNLOAD` | 附件受控下载（成功与失败都记） |
| `EXPORT` | 创建/完成导出任务 |
| `CREATE_GRANT` | 新增或撤销单条授权 |
| `ARCHIVE` | 归档人才 |
| `DELETE` | 逻辑删除附件 |

`ip_digest` / `user_agent_digest` 仅存 SHA-256 摘要，**不存原始值**。
