# 云端输出参数接线与真实验收（2026-10-07）

本机图像创作页面的尺寸、数量、GPT 画质及格式可独立选择，一项修改不再连带改动其他项。只有已登记的型号、能力及参数值允许真实提交；默认参数保留原有能力门禁。后端再次校验，浏览器不可覆写。千问、万相没有套用 GPT 的画质和格式字段。

## 本轮真实验收

用户授权最多 12 次请求、24 张图片。本轮实际发起 12 次生成/编辑 POST，合计请求 18 张，没有自动重试；下载并核对了 12 张真实图片。每型号各 1 次文生图、1 次单参考图编辑。文生图请求 1024×1024 / 1 张；编辑请求 1536×1024 / 2 张。GPT 分别附 low / PNG、medium / JPEG，其他型号只传尺寸与数量。

| 型号 | 文生图参数验收 | 参考图编辑参数验收 |
| --- | --- | --- |
| gpt-image-2.5-flare | HTTP 200、data 1；下载域名检查中断且本次原响应未保存，图片证据缺失，未开放自定义文生图 | 2 张实测 1536×1024；已开放尺寸、数量；请求 JPEG 实际 PNG |
| gpt-image-2.5-sunburst | 同样原响应未保存，不登记本次自定义参数；此前默认文生图已通过，继续可用 | 2 张实测 1536×1024；已开放尺寸、数量；请求 JPEG 实际 PNG |
| qwen-image-3.0 | 1 张实测 1024×1024，开放 | 2 张实测 1536×1024，开放 |
| qwen-image-3.0-pro | 1 张实测 1024×1024，开放 | 2 张实测 1536×1024，开放 |
| wan2.7-image | 1 张实测 1024×1024，开放 | HTTP 400：Model not exist；本次双图横向参数不开放，历史默认编辑仍保留 |
| wan2.7-image-pro | 1 张实测 1024×1024，开放 | ProxyError，未得到结果，未重试；本次自定义参数不开放，历史默认编辑仍保留 |

GPT 编辑保存的原响应可只读恢复下载，不重新生成。鉴权供应商响应给出的图片域名为 rolldek.com，加入精确 HTTPS 下载白名单；继续核验公共 DNS、拒绝重定向、不附供应商授权头，不使用通配符。不能据此宣称该域名与供应商的所有权关系。

GPT JPEG 被忽略，不开放 JPEG 的真实提交。质量字段没有响应确认，只能报告请求受理，不能证明画质档位生效，显式画质选择仍待验证。PNG/WEBP、纵向尺寸、2K 等其他显式参数也不继承其他型号或能力的结果。候选值可用于配置预览，页面会标识待验证，并在提交前拦截。

## 传参及批量结果

output 对象携带 size、n、quality、outputFormat；前端草稿、API、Java DTO、任务快照、幂等比较、执行服务与供应商 JSON/multipart 完整传递。数量上限 2。显式尺寸、格式核对实际图片，返回数量严格与快照相等，先验证整批再归档。每张图片都有所属用户、租户和任务；第一张为封面，详情 outputAssets 支持逐张预览及按实际格式下载。

资源 cloud-image-output-validation.json 登记 8 条尺寸/数量证据；verifiedFields 区分真正通过的参数与仅被受理或被忽略的字段。默认值不强制发送自定义参数。透明背景不提供 JPEG；仍保留以前通过的默认透明 PNG 流程。Flux 保持前端移除。ComfyUI、本地视频和生产配置未更改，本轮没有上线。

## 验证与边界

后端 39 项离线回归、前端 28 项回归、vue-tsc 类型检查通过。另用 8 份捕获的真实供应商响应在回环 HTTP 服务重放，验证 SQL 快照、参数传递、全部 12 张图片文件归档、租户/用户归属、缩略图、幂等与一次请求限制；该重放不请求供应商，不代表额外真实生成。浏览器操作验证了千问文生图和 GPT 双图编辑的提交按钮可用，以及格式切换保留尺寸与数量。

本机使用真实 Java 服务/客户端及隔离 H2、素材存储，开发会话不是生产完整鉴权部署；本地 ComfyUI/视频预览仍为样例。12 次本轮供应商验收由后端探针调用，未再次从浏览器提交，以免超预算。此前 Sunburst 默认文生图的完整页面链路已单独验收。

## 具体默认值界面更新

经用户确认，已验收的尺寸与数量按型号和能力自动选中，实际进入任务快照及供应商请求；选定尺寸时 n=1 也显式发送。编辑默认匹配已验收的 1536×1024 / 2 张档位，仍可独立改为 1 张。首次优先选择具备明确文生图参数证据的型号。未验收能力不凭空补默认值，不影响历史最小请求的兼容性。

页面删除“供应商默认”文案。GPT 画质显示具体 low/medium/high 选项，未指定时明确标识没有指定档位；千问、万相标识无画质档位参数。格式显示对应能力实测 PNG，并明确未指定格式参数；该产出事实不冒充显式 output_format 验收。PNG/JPEG/WEBP 的显式选择继续按原门禁核验。本次没有追加供应商调用或生产发布。
